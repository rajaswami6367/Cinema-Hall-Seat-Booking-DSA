\# CINEMAX – Cinema Hall Seat Booking System



\## Project Overview

CINEMAX is a console-based cinema hall seat booking system developed using C language.



\## Features

\- Display 5x5 cinema seat layout

\- Search for the first available seat

\- Calculate memory address of a selected seat

\- Display base address, offset and element address



\## DSA Concepts Used

1\. 2D Array

2\. Linear Searching

3\. Address Calculation



\## Technology Used

\- Programming Language: C

\- Compiler: GCC

\- Editor: Visual Studio Code



\## How to Run

Compile:

gcc main.c -o cinema\_test.exe



Run:

.\\cinema\_test.exe
